# 🔐 Password Generator

A simple and secure **Password Generator application** built using Python and Tkinter as part of the **CodSoft Python Programming Internship – Task 3**.

The application allows users to specify the desired password length and generates a random password using a combination of letters, numbers, and special characters.

## ✨ Features

* 🔢 Specify desired password length
* 🔠 Uppercase letters
* 🔡 Lowercase letters
* 🔢 Numbers
* 🔣 Special characters
* 🔐 Random password generation
* 📋 Easy-to-use graphical interface
* ⚠️ Input validation and error handling

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter**
* **Random**
* **String**

## 🚀 How to Run

### 1. Clone the Repository


### 2. Open the Project

Navigate to the Password Generator folder:

```bash
cd CODSOFT_TASKSNO/Task3_Password_Generator
```

### 3. Run the Application

```bash
python main.py
```
