# 🧮 Pro Calculator

A modern scientific calculator built with Python and Tkinter. It features a clean user interface, light/dark themes, scientific functions, memory operations, calculation history, and keyboard shortcuts.

---

## ✨ Features

- ➕ Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division

- 🧠 Scientific Functions
  - sin()
  - cos()
  - tan()
  - log()
  - sqrt()
  - Power (^)
  - π and e constants

- 🎨 Modern UI
  - Dark Mode
  - Light Mode
  - Responsive button layout

- 📜 Calculation History

- 💾 Memory Functions
  - MC (Memory Clear)
  - MR (Memory Recall)
  - M+
  - M-

- 📐 Degree/Radian Mode

- ⌨️ Keyboard Support
  - Enter = Calculate
  - Escape = Clear
  - * → ×
  - / → ÷

- ❌ Error Handling
